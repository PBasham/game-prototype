# Assets

Every placeholder the game uses, with the size and layout real art must match.
Swap a file for real art with the same name and layout and nothing else changes.
Pixel scale: 1 tile = 16x16 px. Art is drawn at 1x; the game scales it up.

Placeholders are generated by `tools/generate_tiles.gd`:

```
godot --headless --path . --script res://tools/generate_tiles.gd -- --style=rough
```

Styles: `rough` (current), `soft`, `crumbly`. Add `--out=DIR --preview` to render a
mock scene without touching the game's assets.

## Blocks: `tiles/blocks.png`

768 px wide, 16 px per material row. Each row has **48 tiles**: 16 edge shapes x 3
random variants. Column = `mask * 3 + variant`.

The mask says which neighbors are present (bit set = neighbor there, so no rough edge
on that side): `1` up, `2` right, `4` down, `8` left. Mask 15 = surrounded (plain
interior tile), mask 0 = a lone block with rough edges all around.

## Player: `sprites/player_placeholder.png`

32x64 px single frame, feet at the bottom edge, facing right. The collision box is
24x60 px, bottom-centered (about 1.5 x 3.75 tiles; fits through 2-wide, 4-tall gaps).
Animation frames come later; the frame size stays 32x64.
