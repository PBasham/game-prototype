# Assets

Every placeholder the game uses, with the size and layout real art must match.
Swap a file for real art with the same name and layout and nothing else changes.
Pixel scale: 1 tile = 16x16 px. Art is drawn at 1x; the game scales it up.

## Tiles: `tiles/placeholder_tiles.png`

128x32 px atlas, 16x16 tiles, 8 per row. Generated by `tools/generate_placeholders.gd`.
Coordinates are (column, row).

| Coords | Tile |
| --- | --- |
| (0,0) | dirt |
| (1,0) | grass (dirt with grass top) |
| (2,0) | stone |
| (3,0) | sand |
| (4,0) | snow |
| (5,0) | ice |
| (6,0) | mud |
| (7,0) | clay |
| (0,1) | wood_planks |
| (1,1) | copper_ore |
| (2,1) | iron_ore |
| (3,1) | silver_ore |
| (4,1) | gold_ore |
| (5,1) | arcanite_ore (placeholder magic ore) |
| (6,1) | dirt_wall |
| (7,1) | stone_wall |

Note: the final tile format (single tiles vs. auto-tiling sets with edge variants) is
decided in Phase 1; this list will change then.
